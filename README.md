# Alfa Reward Tracker

Telegram-бот для личного учета мотивации мобильного банкира.

## Логика встреч

### 1. РФ
Пользователь выбирает основной продукт (кнопки не дублируют слово «РФ» —
оно и так видно в заголовке экрана):
- X5 — 340 ₽
- ДК — 340 ₽
- КК — 600 ₽
- Перевыпуск RE — 340 ₽

После этого можно добавлять дополнительные оферы.

### 2. Нерезидент
- X5 — 340 ₽
- ДК — 600 ₽
- КК — 600 ₽

### 3. Установка
- Установка — 340 ₽. Дополнительный экран оферов не нужен.

## Дополнительные оферы

Экран дополнительных оферов состоит из:
- **Быстрые оферы** (одно нажатие, без подменю и без ручного ввода суммы):
  - 📱 **Смарт** — +30 ₽ (перенос в стату месяца — см. ниже).
  - ✈️ **Доп. тревел** — фиксированные +280 ₽.
  - 👶 **Детская DC CROSS KIDS** — +450 ₽.
- **Группы с подменю**:
  - 🛡 **Страховка** — первым в списке идёт «Страхование СС (PPI/CC),
    Действующая (T+30)», остальные тарифы КС — ниже. Все страховки
    переносятся в стату месяца (см. ниже).
  - 📈 **Инвестиции** — только продукты, напрямую связанные с инвестированием
    (брокерский счёт, инвесткопилка, ИЗК).
  - 💰 **Накопительный** — отдельный раздел под накопительные продукты
    (накопительный счёт, НС «Миллионер», ПДС).
  - 💳 **Комбо** и 📶 **Доп. симка** — без изменений.

## Перенос Смарт/страховки на следующий месяц

Смарт и все виды страховок фиксируются в отчёте за сегодня в момент продажи,
но в официальную статистику месяца попадают только 1-го числа **следующего**
месяца. Например, всё, что продано в сентябре, добавляется в стату 1 октября.

Чтобы это было прозрачно, и «Сегодня»/«Отчёт за сегодня», и «Месяц» всегда
показывают **два** числа:
- «Итого (со Смарт/страховкой)» — общая сумма, включая Смарт и страховки;
- «Без Смарт/страховки» — та же сумма без учёта этих категорий.


## Защита от дублей и удаление

- Один и тот же офер с одним `code` нельзя добавить к одной встрече дважды.
- При попытке повторного добавления бот сразу показывает предупреждение.
- «Удалить последний» показывает название и сумму конкретного удалённого офера.
- При удалении последней встречи бот показывает ID, тип, сумму и список удалённых оферов.

## Отчеты

- **«Сегодня»** — отдельный просмотр с двумя суммами:
  - «Итого (со Смарт/страховкой)»;
  - «Чистыми (без Смарт/страховки)».
- **«Отчёт за сегодня»** — детальный список встреч за текущий день с теми же двумя итогами.
- **«Месяц»** — сначала показывает три кнопки в один ряд: предыдущий / текущий / следующий месяц. Можно листать месяцы относительно открытого месяца.
- После выбора месяца график и вся разбивка выводятся **одним сообщением**: картинка + подпись с двумя итогами + основные продукты + дополнительные продукты + отложенные оферы.
- Если QuickChart недоступен, бот отдаёт ту же месячную сводку текстом, без падения.
## Откат
- В процессе добавления встречи можно удалить последний офер.
- В главном меню можно удалить последнюю встречу целиком.
- Можно отменить незавершенную встречу.

## Запуск

```bash
python -m venv .venv
```

Windows:

```bash
.venv\\Scripts\\activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Создай рядом с `bot.py` файл `.env` (за основу можно взять `.env.example`):

```env
BOT_TOKEN=твой_токен_от_BotFather
ALLOWED_USER_IDS=
BOT_TIMEZONE=Europe/Moscow
```

Запуск:

```bash
python bot.py
```

## Проверка логики без Telegram

```bash
python test_logic.py
```

Проверяет каталог оферов (группы, перенос Смарт/страховки, фиксированную
цену тревела и порядок страховок) без обращения к Telegram или сети.
