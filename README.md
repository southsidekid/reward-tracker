# 🅰️ Reward Tracker

Телеграм-бот для учёта встреч и мотивационных выплат. Ведёт статистику по дням и месяцам, считает «чистыми» и «со Смарт/страх», разделяет разовые и отложенные выплаты.

## Возможности

- **Быстрый ввод**: `дк рф смарт защитник` — создаёт встречу и оферы одной строкой.
- **Активность**: пошаговое добавление встречи через кнопки (категория → продукт → ID → оферы).
- **Повтор предыдущей**: копирует состав последней встречи за сегодня.
- **Статистика**:
  - 🧾 **Отчёты** — список дней с активностью + редактор любой встречи (ID, оферы, удаление).
  - 📈 **Месяц** — график по дням, разбивка на основные/доп/отложенные.
  - 🕘 **История** — последние 10 встреч с датой и временем.
- **Погода** на главном экране (Open-Meteo, без ключа).
- **Случайные советы** по алиасам и фичам при каждом открытии меню.
- **Авто-ID** формата `АВТО-ДДММ-ЧЧММ`, кнопка «Пропустить».

## Стек

- Python 3.11+
- [aiogram 3.x](https://docs.aiogram.dev/)
- SQLite
- [Open-Meteo](https://open-meteo.com/) — погода
- [QuickChart](https://quickchart.io/) — график месяца
